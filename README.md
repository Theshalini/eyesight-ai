# Eyesight AI

## Overview
Eyesight AI is an AI-powered eye disease detection system developed using Streamlit and Machine Learning techniques. The application predicts possible eye-related conditions from uploaded retinal images.

## Features
- Retinal image upload
- AI-based disease prediction
- User-friendly Streamlit interface
- Prediction confidence display
- Image preprocessing pipeline

## Tech Stack
- Python
- Streamlit
- TensorFlow
- OpenCV
- NumPy
- Pandas

## How to Run

1. Clone the repository, and the model is given as a zipped folder unzip it to use.
2. Install dependencies

pip install -r requirements.txt

3. Run the application

streamlit run app.py
